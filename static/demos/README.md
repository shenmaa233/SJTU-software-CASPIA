# Demo Files Directory

This directory is for storing demonstration GIF/video files to be displayed on the CASPIA home page.

## Required Demo Files

Please add the following demo files to this directory:

1. **caspiagent_demo.gif** - Demonstration of CASPIAgent conversational AI
2. **gemfactory_demo.gif** - Demonstration of GEMFactory metabolic modeling
3. **rag_demo.gif** - Demonstration of CASPIA-RAG document analysis
4. **monitor_demo.gif** - Demonstration of Tasks Monitor dashboard

## File Specifications

- **Format**: GIF or MP4
- **Resolution**: 800x600 or 1280x720 (recommended)
- **File Size**: < 10MB (for optimal loading performance)
- **Duration**: 10-30 seconds
- **Frame Rate**: 10-15 fps for GIF, 30 fps for MP4

## Tips for Creating Good Demos

1. **Keep it focused**: Show one clear workflow or feature
2. **Add annotations**: Use arrows or text overlays to highlight key actions
3. **Use realistic data**: Demonstrate with actual use cases
4. **Optimize file size**: Use tools like ezgif.com to compress GIFs
5. **Test loading**: Ensure demos load quickly in the web interface

## Optimization Tools

- **GIF Optimization**: https://ezgif.com/optimize
- **Video to GIF Conversion**: https://ezgif.com/video-to-gif
- **Screen Recording**: OBS Studio, ScreenToGif, QuickTime (Mac)

## After Adding Files

Once you've added your demo files:
1. Update the file paths in `tabs/index_tab.py`
2. Follow the instructions in `CUSTOMIZE_HOME.md`
3. Restart the web server to see your changes
